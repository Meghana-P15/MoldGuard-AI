# Knowledge documents

The RAG service indexes `.md` and `.txt` files in `knowledge/docs/`.

The included documents are:
- a real-data operating envelope generated from `modelo.xlsx`
- the real electrical-model evidence note
- the human-review policy

For a factory deployment, add the plant's approved SOPs, process-window documents and machine/material guidelines here. Do not treat the generated operating-envelope document as an OEM SOP.
